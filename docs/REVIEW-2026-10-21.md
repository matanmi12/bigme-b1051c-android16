## 4. ה-ROM: InKognito alpha 1

  - 6 מודולים: eink-compat 0.1.28, launcher3, bootanim, fonts, icons, ו-gapps עם Setup Wizard
  - 7 APK: Magisk, E-Ink Control 0.15.3, einkui, launcher overlay, iconpack, Lawnchair, KOReader

  - ברירות המחדל
  - ה-hook `inkognito.rc`
- **`boot.img` / `vbmeta.img` / `logo.img`:** זהים ב-bytes ל-boot_b, ל-vbmeta_b ול-logo שלך (`f6d59171` / `12e57602` / `1b580939`).

  | שלב | פעולות |

  | LK | vbmeta_X, boot_X, logo |
  | fastbootd | system_X עם suffix מפורש, `-w` (ואם לא מחק, `erase` של userdata ו-metadata), ‏`set_active X` |

  - `--strict-slot` עוצר בכל אי-התאמה, ו-`--dry-run` רק מדפיס.
- **מסמכים:** README, INSTALL, KNOWN-ISSUES, CHANGELOG, CREDITS, LICENSES ו-licenses/.
